# Password Manager

A simple Python application for securely storing and managing website credentials.

## Features

* Add new website credentials
* View all saved passwords
* Search passwords by website
* Save passwords to a text file
* Load saved passwords automatically when the program starts

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* File Handling

## Project Structure

```text
password-manager/
│
├── main.py
├── passwords.txt
└── README.md
```

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```

## Example

```text

2. View Passwords
3. Search Password
4. Exit

Website: Steam

Password: ********
```
